# 《宝可梦 · 卡牌远征》演示解说词

建议时长约 90 秒。下列画面提示供实际录屏使用；仓库同时提供立绘海报、玩法示意图以及线上版本的地图和战斗实机截图。

| 时间 | 建议画面 | 解说词 |
| --- | --- | --- |
| 0–10 秒 | 标题页，点击开始 | 如果把宝可梦的属性战斗和 Roguelike 卡牌构筑结合起来，会是什么样？这就是《宝可梦·卡牌远征》，一款打开网页就能体验的同人小游戏。 |
| 10–25 秒 | 选择伙伴，展示说明 | 冒险从选择伙伴开始。小火龙擅长灼伤与爆发，杰尼龟偏向防御，妙蛙种子适合持续消耗。不同伙伴带来不同的起始策略。 |
| 25–40 秒 | 地图路线与节点 | 地图采用分支路线。战斗、精英、事件、商店和休息点各有作用。生命不足时可以寻找休息点，牌组需要调整时则可以考虑商店。 |
| 40–60 秒 | 普通战斗，出牌与结束回合 | 先看敌人的行动意图，再分配自己的能量。什么时候攻击，什么时候格挡，是否利用属性克制或叠加状态，都由你决定。卡牌还有保留、消耗、多段和 X 费等机制。 |
| 60–75 秒 | 奖励选牌、遗物、强化 | 每一场胜利都可能改变牌组方向。选牌不只看单卡强度，还要考虑现有组合；遗物和强化则让策略进一步成型。 |
| 75–90 秒 | 首领节点或战斗 | 最终目标是突破三层区域并击败首领。项目使用原生前端实现，结合 SVG 立绘、Canvas 特效和程序化音效。欢迎下载体验，也欢迎通过 Issue 反馈问题。 |

## 发布配文

做了一个宝可梦主题的 Roguelike 卡牌小游戏：选伙伴、走路线、构筑牌组，再挑战三层首领。支持属性克制、敌人意图、遗物与卡牌强化，纯前端实现，打开网页即可游玩。项目中也整理了源码结构和玩法说明，欢迎体验交流。
